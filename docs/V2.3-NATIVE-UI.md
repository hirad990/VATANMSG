# VATANMSG V2.3 — Native-feeling UI refresh

This branch adds the first V2.3 UI and profile pass on top of the V2.2 fixes.

## Implemented in this branch

- **Personal appearance controls:** six accent colors, light/dark mode, compact message layout, and a smooth-animation toggle. Preferences are persisted in local app storage.
- **Less bulky chat bubbles:** smaller avatars, tighter spacing and reduced bubble padding when compact mode is enabled.
- **Keyboard-aware composer motion:** the composer gets a small animated lift when the keyboard opens/closes; the chat remains inside a native `KeyboardAvoidingView`.
- **Tap-through user profiles:** tapping a username in chat or a name in Contacts opens the user's profile, with a Message action.
- **Optional public profile links:** website, Instagram, Telegram and YouTube links can be saved in the user's own profile and are shown only when present. Links are HTTPS-validated by the API and opened externally.
- **Voice notes:** record and send a short voice note from the composer; received audio attachments can be downloaded and played in-app. Existing image/video/document attachment controls remain available.
- **Server support:** the PHP API returns public profile links, supports authenticated profile lookup and accepts a constrained list of audio MIME types.

## Existing database upgrade required

The PHP API now reads four additional columns from `users`. On the existing MariaDB database, open phpMyAdmin, select the VATANMSG database, and run:

`php-api/migrations/2026-10-v2.3-profile-links.sql`

Run each `ALTER TABLE` only once. If a column already exists, skip that statement. Without this migration, the updated API will return a database error on profile endpoints.

Fresh installations can use the updated `php-api/schema.sql`.

## Notes / validation

- Profile links are optional and are visible to signed-in users who open a profile; do not put private information in these public fields.
- Voice upload is limited by the existing API upload ceiling and host-level PHP limits. The server MIME detector must recognize the recorded format.
- GitHub Actions passed TypeScript typecheck and PHP syntax validation for the current branch head.
- Real-device keyboard animation, microphone permission, audio playback, and live cPanel/database integration still need to be verified before merging into `main`.
- This branch does not claim the whole application is fully QA-tested.
